## 5. Architectural & Security Risk Analysis
1. **Risk of Automated Mutation**: Higher evaluation metrics triggering automatic production promotion.
   - *Mitigation*: Hard-coded domain invariant that evaluation PASS generates only `APPROVED_IMPROVEMENT` candidate state, requiring explicit human action for future execution.
2. **Risk of Secret Leakage**: Secret-bearing content entering evaluation logs or metrics.
   - *Mitigation*: Re-validation using secret regex auditing in `run_pre_evaluation_validation()`.
3. **Risk of Production DB Mutation**: Test executions polluting `data/database/brud_ai.db`.
   - *Mitigation*: Strictly isolated `:memory:` or temporary SQLite databases for all automated unit and integration tests.
