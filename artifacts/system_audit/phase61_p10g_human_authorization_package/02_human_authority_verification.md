# 02 HUMAN AUTHORITY VERIFICATION AUDIT

- Authorized Human Roles: `HUMAN_ADMIN` / `LEGAL_OFFICER` (sole human authority).
- Non-Authorized Roles: `ADMIN_ASSISTANT_ADVISORY` (strictly advisory only, 0 token-signing or activation capabilities). `SECURITY_AUDITOR` and `SYSTEM_OPERATOR` strictly prohibited from self-authorizing production changes.
