# Phase 17.7 — Consolidation & Dispute Integration Report
**Brud Mini Brain: Cross-Phase Compatibility with Consolidation (17.6) and Disputes (17.5)**

## 1. Interaction with Phase 17.6 Memory Consolidation
Phase 17.7 seamlessly integrates with canonical consolidated knowledge:

### 1. Freshness Inheritance:
- A canonical memory generated by Phase 17.6 inherits its base freshness from the **most recent** constituent source observation:
  $$\text{created\_epoch}_{\text{canonical}} = \max_{i} (\text{created\_epoch}(M_i))$$
- As constituent sources age, the canonical record follows standard category decay curves unless reinforced by fresh observations.

### 2. Source Memory Expiration vs Canonical Validity:
- When a constituent memory record reaches TTL expiration, it transitions to `status = 'expired'`.
- The canonical consolidated knowledge record remains active as long as its aggregate evidence and validity window remain active.

### 3. Unconsolidation Lifecycle Restoration:
- Executing `unconsolidate_memory(canonical_id)` restores constituent sources to `status = 'active'` and marks the canonical record `status = 'superseded'`.
- Their individual freshness states are immediately re-evaluated against their original creation timestamps.

## 2. Interaction with Phase 17.5 Conflict & Dispute Engine
Phase 17.7 strictly respects active disputes:

### Dispute Protection Gate:
Any memory item linked to an active `DisputeRecord` in states:
- `DETECTED`
- `PENDING_REVIEW`
- `UNDER_REVIEW`

is **IMMUNE to autonomous expiration and autonomous archival**.
- Disputed memories cannot be silently swept away or aged out while administrative arbitration is pending.
- Resolved disputes apply standard lifecycle rules according to their resolution strategy:
  - `SUPERSEDE_EXISTING`: Superseded item transitions to `superseded`; superseding item becomes active with fresh validity window.
  - `RETAIN_EXISTING`: Authoritative memory remains active; rejected candidate memory is retained in audit history as `rejected`.
  - `RETAIN_BOTH_COEXIST`: Both memories undergo independent category decay without cross-pollution.
  - `DISMISS`: Original items resume normal category freshness tracking.
